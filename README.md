📊 Ecommerce Sales Analytics Dashboard (Excel)

An interactive Excel dashboard created using a 9,995-row ecommerce dataset, showcasing sales, profit, category performance, state-wise revenue, and KPI trends.

🔹 Project Summary

This project covers the complete analytics workflow in Microsoft Excel, including data cleaning, KPI creation,
pivot table modeling, and interactive dashboard design using slicers and multiple chart types.

🔹 Tools Used

Microsoft Excel: Pivot Tables, Pivot Charts, Slicers, Map Chart, Waterfall Chart, Donut Chart, Conditional Formatting, Sparklines.

🔹 Key Features

KPI Cards: Sales, Profit, Orders, Quantity, Profit Margin, YOY Growth

Interactive Slicers: Year, Segment, Region.

Visualizations:

Monthly Sales vs Profit (Combo Chart)

Category-wise Sales Share (Donut)

Category-wise Profit (Bar Chart)

Top Sub-Categories (Horizontal Bar Chart)

State-wise Sales (Map Chart)

Profit Contribution (Waterfall)

KPI Trend Sparklines

🔹 Key Insights

Highest sales in Nov & Dec

Technology category drives maximum sales & profit

California is the highest-revenue state (~$457K)

Phones is the top-selling sub-category

Strong Q4 performance across all segments

🔹 How to Use

Download the Excel Project.xlsx file.

Open in Excel.

Use slicers to filter by Year, Segment and Region.

All charts & KPIs update automatically.
